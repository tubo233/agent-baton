# 任务书与启动提示：模板和写法要点

## 写法要点（来自实际踩过的坑）

- **让执行方不用提问。**代理是无人值守运行的，没人回答它的问题。含糊的地方，要么在任务书里定死，要么写明"自己按最稳妥的方式决定，记进报告，继续做完"。
- **可做范围写宽，禁止事项写准。**有的代理会把没点名允许的输入都当成禁区，然后跳过那一步。可读范围写成"本项目自己的所有数据和既有结果"这样的大范围，只把真正的禁区（私人材料、受保护数据、来源目录）列为禁止。
- **要判定的内容写成命题，不要写成问题。**
  - 写"该文在 X 数据集上评估，使用 80%/20% 划分"，不要写"它用了什么划分？"。
  - 判定只取几个固定值，如"成立 / 部分成立 / 不成立 / 全文中未找到"。
- **阅读类任务必须有"读过的页"一栏，并核对文件名与题目。**防止拿片段冒充全文，也防止文件对错论文。
- **不让执行方发挥"与本项目的关系"。**这类段落容易拿领域外的类比硬说"印证""同构"。只让它判定命题本身。
- **给出显示值，让它报告对不上的。**核对数字时，把文中的显示值告诉它；重算对不上就写进报告，不许改来源去迁就。
- **引用原文要短**（英文每处不超过 15 个词），其余转述。
- **自查放在最后，有证据。**能开上下文全新的子代理，就让子代理随机抽几项，重新打开原始文件核对；不能就自己另起一遍。写下查了什么、错了什么、改了什么。
- **输入预先准备好。**
  - 阅读任务：把 PDF 按页抽成文本（如 `pdftotext -layout`），每页加 `=== 第 N 页 ===` 标记，放进 `输入/全文/<简称>.txt`。
  - 代码任务：给出仓库路径、测试命令、解释器的绝对路径。
- **说明运行环境的限制。**比如"不能跑终端命令""沙箱写不了 .git""不能联网"，以 references/agents.md 和个人配置为准。
- **写明它是执行方。**它也会看到 baton 这类 skill，要明确告诉它不要再分派。

## 任务书模板（`任务书.md`）

```markdown
# 任务书：<一句话任务名>（<日期>）

## 背景

<两三句：这是什么项目、为什么要做这件事。不用内部编号；必要的术语给一句解释。>

## 可以读、可以写的范围

- **可读：**<列全，范围写宽>
- **可写：**<任务文件夹；需要改动的具体目录>
- **禁止：**
  - <私人材料、受保护数据、来源目录等，以个人配置和项目规则为准>
  - <本任务特有的禁止项，如"不改正文""不联网""不跑训练""不碰 .git">
- **工具：**<解释器绝对路径、编译器路径、下载用的代理地址；不能跑命令的写"不要运行终端命令">

## 要做的

### 任务 1：<名字>
<步骤、规则、取值约定。给出文件简称表和筛选条件。>

### 任务 2：……

## 硬性规则

1. 只在可写范围内写。
2. <依据什么判定；拿不到的写"未取得"，不要推测>
3. <引用原文的长度限制>
4. <对不上的值写进报告，不要迁就>

## 输出

- `<文件名>`：<格式，如 CSV 表头逐字给出>
- `报告.md`：<依次写哪些内容>
- `自查.md`：能开一个上下文全新的子代理就让它做，不能就自己另起一遍。随机抽 <N> 项，重新打开原始文件核对，写下查了什么、错了什么、改了什么。

这是无人值守运行，没有人能回答你的问题。遇到含糊的地方，自己按最稳妥的方式决定，写进报告，然后继续做完，不要停下来等待。
```

## 启动提示模板（`启动提示.md`）

```markdown
你是执行方。你的工作区是 <任务文件夹>，当前目录就是它。请先完整阅读这里的 任务书.md，然后从头到尾照做，直到写完 <列出所有输出文件>。

要紧的规则：
1. 你是被派出来的执行方：不要使用 baton 之类的分工 skill，不要把任务再派给其他代理或模型。
2. 只在 <可写范围> 里读写，不要访问 <禁止目录>。
3. <联网：不要联网 / 下载文件时用 <下载代理写法>>
4. <工具限制：不要运行终端命令 / 不要用浏览器类工具 / 解释器用 <绝对路径>>
5. 只依据取回或给定的文件写结论；拿不到的写"未取得"，不要推测。

这是无人值守运行，没有人能回答你的问题。遇到需要登录、付费或签协议的资源，记为"需人工获取"后继续下一项；含糊的地方自己决定、记进报告，继续做完。
```

## 给中控自带子代理的提示要点

子代理看不到当前对话，提示里要包括：

- 工作文件夹，以及"只在这里读写"；
- 任务书的完整路径；
- 本批负责的条目清单；
- 用什么工具读文件，例如"按页从头读到尾"；
- 输出文件名，带批次后缀（如 `_A`、`_B`）；
- 自查要求；
- 汇报时要给的摘要：各类判定的数量，以及每个非"成立"项的建议改写和出处。

切分时，每个子代理读的全文控制在约 450 KB 以内（大约 5 篇论文）。
